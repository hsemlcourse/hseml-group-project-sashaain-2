## 1. Введение и постановка задачи

- **Цель проекта:** разработка модели для оценки качества 3Д-мешей на основе их геометрических и топологических характеристик
- **Формулировка задачи:** многоклассовая классификация
- **Обоснование метрики качества:** Основной метрикой качества выбран macro f1-score, так как задача является многоклассовой и классы распределены неравномерно.
  Accuracy использовалась как дополнительная метрика, однако она может быть недостаточно информативной при сильном дисбалансе классов.
  Macro f1-score позволяет одинаково учитывать качество предсказаний для всех классов, включая редкие.

## 2. Поиск и описание данных

- **Источник данных:** найден на hugging face, подходил под задачу и требования - поэтому был выбран
- **Описание датасета:**
  - Объём: около 10000 объектов, 49 признаков
  - Описание признаков (типы, смысл) - все признаки числовые, описывают геометрию и топологию мешей (площадь, углы, количество вершин, дефекты и т.д.)

## 4. Baseline-модель

- **Модель:** простая модель «из коробки» (Linear/Logistic Regression, KNN и т.п.) без feature engineering - Logistic Regression и Random Forest
- **Результаты:** метрики на val/test
  LR показала умеренные результаты, но плохо справлялась с дисбалансом
  RF показал более высокое качество ( accuracy = 0,94)
- **Цель:** точка отсчёта для сравнения с более сложными моделями - выбрана LR, так как это простая линейная модель, которая позволяет оценить минимальынй уровень качества
