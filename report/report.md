## 1. Введение и постановка задачи

- **Цель проекта:** разработка модели для оценки качества 3Д-мешей на основе их геометрических и топологических характеристик
- **Формулировка задачи:** многоклассовая классификация
- **Обоснование метрики качества:** Основной метрикой качества выбран macro f1-score, так как задача является многоклассовой и классы распределены неравномерно.
  Accuracy использовалась как дополнительная метрика, однако она может быть недостаточно информативной при сильном дисбалансе классов.
  Macro f1-score позволяет одинаково учитывать качество предсказаний для всех классов, включая редкие.

## 2. Поиск и описание данных

- **Источник данных:** найден на hugging face, подходил под задачу и требования - поэтому был выбран
  Ссылка: https://huggingface.co/datasets/Thingi10K/Thingi10K
- **Описание датасета:**

  - Описание признаков (типы, смысл) - все признаки числовые, описывают геометрию и топологию мешей (площадь, углы, количество вершин, дефекты и т.д.)

## 4. Baseline-модель

- **Модель:** простая модель «из коробки» (Linear/Logistic Regression, KNN и т.п.) без feature engineering - Logistic Regression и Random Forest
- **Результаты:** метрики на val/test
  LR показала умеренные результаты, но плохо справлялась с дисбалансом
  RF показал более высокое качество ( accuracy = 0,94)
- **Цель:** точка отсчёта для сравнения с более сложными моделями - выбрана LR, так как это простая линейная модель, которая позволяет оценить минимальынй уровень качества

## 5. Эксперименты

Для каждого эксперимента - формат: **Гипотеза** → **Как проверялось** → **Результат** + метрики в таблице.

Logistic Regression

- Гипотеза: линейная модель сможет выявить базовые зависимости между признаками и качеством меша.
- Как проверялось: использовалась Logistic Regression с масштабированием признаков и параметром class_weight='balanced'.
- Результат: модель показала macro F1-score = 0,64 и accuracy = 0,84. Несмотря на хорошие результаты для основных классов, модель хуже справлялась со сложными нелинейными зависимостями и редкими классами.

K-Nearest Neighbors (KNN)

- Гипотеза: локальные зависимости между объектами помогут улучшить качество классификации.
- Как проверялось: были протестированы значения k = 3, 5, 7 после применения StandardScaler.
- Результат: лучшим оказался вариант k=3, показавший macro F1-score = 0,68 и accuracy = 0,85. KNN продемонстрировал более стабильное качество на редких классах по сравнению с Logistic Regression.

Decision Tree

- Гипотеза: дерево решений сможет лучше моделировать нелинейные зависимости между признаками.
- Как проверялось: тестировались значения max_depth = 5, 10, None.
- Результат: лучшим оказался вариант max_depth=10, достигший macro F1-score = 0,79 и accuracy = 0,92. Модель значительно лучше определяла сложные зависимости и редкие классы.

Random Forest

- Гипотеза: ансамбль деревьев решений позволит повысить устойчивость модели и качество классификации.
- Как проверялось: проводился подбор параметров n_estimators и max_depth.
- Результат: Random Forest достиг accuracy = 0,94 и macro F1-score ≈ 0,79. Модель показала высокую стабильность и хорошее качество предсказаний практически для всех классов.

Gradient Boosting

- Гипотеза: бустинг сможет лучше оптимизировать ошибки предыдущих моделей и повысить качество классификации.
- Как проверялось: тестировались различные значения n_estimators и learning_rate.
- Результат: лучшая конфигурация (n_estimators=200, learning_rate=0.05) показала macro F1-score = 0,79 и accuracy = 0,94. Gradient Boosting продемонстрировал лучшие итоговые результаты среди протестированных моделей.

PCA (уменьшение размерности)

Дополнительно был проведён эксперимент с уменьшением размерности данных с помощью PCA с сохранением 95% дисперсии. Размерность признакового пространства была уменьшена с 44 до 27 признаков.

После применения PCA качество моделей снизилось:

- Logistic Regression: macro F1-score снизился с 0,64 до 0,62;
- Random Forest: macro F1-score снизился с 0,79 до 0,67.

Это показывает, что часть важных зависимостей терялась при снижении размерности, поэтому использование PCA для данной задачи оказалось нецелесообразным.

Итоговая таблица экспериментов представлена в файле 03_experiements.ipynb.

## 6. Финальная модель и интерпретируемость

- **Обоснование выбора финальной модели:** В качестве финальной модели был выбран Gradient Boosting, так как он показал наилучшее значение macro F1-score среди протестированных моделей при высоком accuracy. Но для анализа важности признаков был использован Random Forest, который показал сопоставимое качество, поскольку ансамбли деревьев позволяют интерпретировать вклад отдельных признаков в предсказание модели.
- **Интерпретируемость:** Наиболее важными признаками оказались: solid, min_area, PWN. Результаты показали, что на качество меша сильнее всего влияют как топологические характеристики, так и геометрические свойства граней и углов.
