## Описание задачи

Цель проекта — разработка модели машинного обучения для оценки качества 3D-мешей на основе их геометрических и топологических характеристик.

Используется задача многоклассовой классификации: каждому мешу присваивается класс качества от 0 до 4 в зависимости от количества обнаруженных дефектов.

**Задача:** многоклассовая классификация

**Датасет:** набор данных с характеристиками 3D-мешей, найденный на Hugging Face

**Целевая метрика:** Macro F1-score

Macro F1-score был выбран основной метрикой, так как классы в датасете распределены неравномерно, и важно учитывать качество предсказаний для редких классов.

## Результаты

В рамках проекта были протестированы несколько моделей машинного обучения.

| Модель | Accuracy | Macro F1-score | Примечание |

|--------|--------|--------|--------|

| Logistic Regression | 0.84 | 0.64 | Baseline-модель |

| KNN (k=3) | 0.85 | 0.68 | Улучшение качества на редких классах |

| Decision Tree | 0.92 | 0.79 | Хорошо моделирует нелинейные зависимости |

| Random Forest | 0.94 | 0.79 | Высокая стабильность |

| Gradient Boosting | 0.94 | 0.79 | Лучшая итоговая модель |

Дополнительно проводился эксперимент с PCA для уменьшения размерности признакового пространства. После применения PCA качество моделей снизилось, поэтому использование PCA было признано нецелесообразным для данной задачи.
